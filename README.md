# Sigil

Unit frames for WoW Forever: player, target, target of target, focus, pet and
party.

## Features

- **Bars**: health (class, reaction, gradient or custom color, incoming heals
  and shields) and power, inside the frame or detached anywhere.
- **Texts** written in Lua, with helpers that work with the values the game
  hides in combat.
- **Auras** drawn by the game's native container, so they work in combat and
  instances: groups with their own filters, spell lists, size and position.
- **Cast bar**, global cooldown, threat, combo points, experience / reputation,
  druid mana, totems, combat text and status icons.
- **Fading** by range, combat, phase or hostility.
- **Move anything**: unlock and drag every frame and piece, with a grid and
  snapping.
- **Copy settings** between frames by tab, with undo.
- **Profiles** with export / import. English and Spanish.

Optional: Masque (aura skins), Clique (click-casting), LibSharedMedia-3.0.

## Commands

- `/sigil`: open the options
- `/sigil move` / `/sigil lock`: unlock / lock the frames
- `/sigil test`: test frames
- `/sigil reset`: default settings for this character
- `/sigil lang en|es`: language
